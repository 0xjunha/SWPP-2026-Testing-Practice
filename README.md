# Week 7 — Testing

**SWPP 2026 Fall**

Practice repository for writing **unit tests** and **integration UI tests** on a simple Android TODO app.

## Requirements
- Android Studio (latest stable)
- JDK 17+ (the JDK bundled with Android Studio is fine)
- An Android device or emulator (API 24+) for instrumented tests

## Writing a test: Given / When / Then
- **Given (Arrange)** — set up the objects and app state for the test
- **When (Act)** — perform the action on the object
- **Then (Assert)** — check what happens as a result
